# 产品与交互

Softie 是可揉捏、提起和喂糖的三维凝胶角色。体验以直接触摸、软体反应和进食换色为中心，设置用于调整手感、运动与外观。

## 身体与镜头

- 拖动身体可局部揉捏、拉伸或提起；松手后由物理模拟落地、回弹和恢复。
- 固定桌面模式把活动限制在附近，自由空间模式允许更大范围的移动。空间约束应保留普通揉压与局部变形，避免把角色变成僵硬物体。
- 小屏和触控设备默认固定中央视角；可在设置中解除固定。镜头锁定时仍允许双指缩放，解锁时可用空白处拖动环绕。
- 抓身体、拖糖和控制镜头具有明确的操作归属。双指接管后，剩余单指不会意外继续抓取；取消、失焦和捕获丢失应释放操作。
- 镜头避免跟随轻微抖动反复推拉，身体被抓住时保持取景稳定，释放后的较大跳跃仍需留在画面内。
- 切换空间模式会清理当前操作并重置活动区域，界面应说明该行为；模式与部分设置保存在浏览器本地。

## 糖果与进食

- 托盘支持点击放糖和拖出实体糖；场景中的糖可以再次抓取，轻点地上的糖可以发出进食邀请。
- 糖具有空间位置、碰撞与遮挡。手动压入、释放和撤回保持同一颗糖的连续性，不用瞬间删除或替换来表现吃入。
- 自主靠近以观察、准备、离散起跳和真实接触构成，不能通过隔空吸附或空中追踪修正保证命中。
- 身体接触并包裹糖后，逐步吸收、溶解并改变身体颜色。嘴承担表情，不是糖必须经过的入口。
- 一次接触吸收由一颗糖占有；撤回、打断与复位应清理对应状态，不能遗留卡住的糖或额外累计效果。
- 满足反应与可见进食过程衔接，染色可继续缓慢收敛。连续进食保留已有颜色的连续变化。

## 表达与外观边界

表情和体态回应触摸、抓取、落地与进食，直接操作优先于自主表演。眼睛与嘴贴合变形后的皮肤，角色的表情不能与身体运动脱节。

半透明凝胶、内部气泡、黑豆眼、小嘴和柔软轮廓构成视觉身份。移动端优化应优先调整渲染成本，不能未经确认替换材质风格或改变角色身份。
