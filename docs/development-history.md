# softie.

一团用 Three.js + 真正 WebGPU 渲染的可玩史莱姆。

## 启动

需要 Node.js 22.13+ 和 pnpm。进入本目录后运行：

```sh
pnpm install
pnpm dev
```

打开终端显示的 localhost 地址。生产构建：`pnpm build`。

需要支持 WebGPU 的浏览器及图形加速。不要直接双击源码或使用普通非安全的远程 HTTP 地址；WebGPU 需要 HTTPS 或 localhost。

## 玩法

- 按住身体局部揉捏，拖动提起，松手让它下落、挤扁和晃着复原。
- 拖空白处可以 360° 环绕观察，滚轮调整远近，点「回正面」平滑回到初始视角。聚焦画布后也可用方向键转视角、Home 回正面。侧面和背面同样可以抓揉，空间边缘的糖果松手不会跳位。
- 选择软糖或硬糖，再点击色糖丢一颗；拖住色糖可以递、甩、收回。每颗都是有重力、旋转、碰撞和阴影的3D物体，落地后可以再次抓起。可以连续丢很多颗，吃糖期间也能继续丢。
- 它会看糖、压低身体后小跳靠近，用身体接触并包裹糖果，一次吸收一颗。还拿在手里的糖由玩家控制；约七颗吃饱后停止追逐，剩糖保留，休息一段时间恢复食欲。键盘聚焦色糖后按 Enter/空格也可以丢糖。
- 糖接触身体后保留原有压缩形态，先从接触处进入，再缓慢沉到下腹。体内仍能看见同一颗糖，边缘逐渐变圆、融化，颜色从内部柔和扩散。嘴只负责表情。
- 鼠标不按下，慢慢扫过身体表面，它会舒服地眯眼、轻轻左右摇摆，短暂贴近手指后回到居中。连续短促地戳会惹它生气：缓缓鼓成三维圆球，脸和皮肤一起变形，消气后更慢地缩回原状。正常拖拽不算猛戳。
- 右侧滑块调整软硬与阻尼。圆箭头同时恢复外观、手感和情绪，并取消正在进行的喂食。
- 点击「戳一下」或聚焦史莱姆后按空格。圆箭头恢复默认。
- 支持鼠标和触控；双指可以同时压两块皮肤，滑块支持方向键、Home、End。
- 收回它已经期待的糖，会先失落，再鼓起一点小脾气。鼓气仍能揉压，放手回弹，慢慢抚摸会消气。吃饱后的收回不生气。
- 摸舒服了会冒爱心泡泡，重落地有星星泡泡，都可以点破。安静约一分钟会趴低睡着，睡泡随呼吸起伏，轻点唤醒。声音默认关闭，可在右侧打开。

## 实现

`lib/slime-scene.ts`：Three.js r183 WebGPU 场景、摄影棚柔光、透射物理材质、背面光学界面、射线拾取、实例化气泡和三层接触阴影。小脸由贴合皮肤的微型网格构成；每个顶点与身体共享材料坐标和同一形变场。支持眨眼、视线跟随、受压眯眼和弹起时张嘴。

`lib/slime-physics.ts`：固定 120 Hz 的弹簧动力学，包含重力、桌面接触、保体积的压扁/椭圆模式、两向剪切和三维局部弹性位移。松手保留位移和速度，因此表面连续回弹。带径向补偿的局部形变会让周围软肉一起响应。落地冲量传递到压扁模式，静止后保留落地点。它是为交互手感设计的弹性形变模型，不是完整的体积有限元模拟。

`lib/slime-character.ts`：与渲染独立的情绪和 6.1 秒吸收周期，区分轻抚、快速连续戳、包裹、融化与满足。包裹完成时增加一次饱腹，忙碌时拒绝新糖不会改变正在进行的吸收。旧口部进食时序作为兼容代码保留，当前场景不再调用它。

`lib/slime-tissue.ts`：19 层耦合弹簧沿身体传递接触波，用轴向补偿限制径向变形引起的体积变化。它补充现有全局模式和局部揉捏场，属于可控的小应变近似，不是完整体积 XPBD 或有限元求解器。

`lib/slime-optics.ts`：实际变形几何的前后深度层提供厚度；内部气泡和糖单独渲染深度，再按遮挡、透射距离与轻微折射合成。摄影棚光源提供高光和轮廓。仍是实时光学近似，未使用路径追踪、多次体积散射或真实焦散。

`lib/slime-orbit.ts`：带阻尼的球坐标视角、当前视角下的抓取平面，以及按实际变形轮廓计算的镜头留白。快速提起鼓圆的身体时立即让出画面空间，放下后缓慢拉回。`slime-shape.ts` 的预计算材料高度表把原始轮廓连续映射到圆润的球体，保留柔软接触底面和局部揉压。

`lib/candy-physics.ts` / `candy-renderer.ts`：固定步长、冲量、摩擦与休眠，软糖压缩和硬糖弹跳旋转。糖之间使用小凸体接触近似；`slime-contact.ts` 使用与身体相同的截面和形变场处理外皮接触，包括鼓气与饱腹。

`lib/slime-absorption.ts`：当前场景的目标选择、蓄力小跳和外皮接触。糖从材料坐标中的接触点平滑进入身体，与皮肤共享形变场；吃饱或被提起时停止自主追逐。`candy-pointer.ts` 防止取消、多指和失焦串改另一层持有的糖。

旧的 `slime-feeding.ts`、`slime-syrup.ts` 和口部时序测试保留用于历史回归，但已退出当前场景。`slime-feedback.ts` 管理有限寿命的实体情绪泡泡、睡泡和默认关闭的合成轻音效。

明确将 r183 的 `_getFallback` 设为 `null`，在初始化前关闭 Three.js 自动 WebGL 回退，并在初始化后验证 `isWebGPUBackend`。WebGPU 不可用或设备丢失时显示说明，不降级到 WebGL。

6050 个焊接主体顶点、84 个分布在前后不同深度的实例化微气泡。表面截面预计算为查找表，避免脸部每帧反复求解曲面。像素比会在 0.85–min(devicePixelRatio, 1.5) 之间按帧率调整；页面角落显示实测帧率。刷新率和硬件不同，数值也会不同。

## 外观样片 `/lookdev`

默认把可旋转的 WebGPU 模型与原始 AI 概念图并排。可切换侧前方、正面、侧面，凝胶/灰模，以及自然、压低、鼓圆和呼吸；拖动画布或方向键可环绕。完整喂糖玩法仍位于 `/`，外观模型尚未接入该玩法。按用户要求，当前更新仅在本地预览。

### 2026-09-09：按概念图校准的混合材质

身体改为宽低腹部、圆润冠部和更长的落地接触面；黑豆眼下移、拉开眼距并增加真实曲面厚度，嘴保持小而浅的弧线。`assets/create-slime-studio.py` 用 Blender 4.5 LTS 重建 `.blend` 与 GLB：主体 8,962 个顶点，脸和身体共享 Breathe/Squash/Puff 三套形变，158 个有空间深度的气泡。形变仍是美术控制的姿态插值。

单纯提高物理透射参数、以及前后界面解析折射的实验，均未得到目标图的光感。最终采用 **材质捕获 + 真实三维光学层**：

- `public/materials/slime-gel-matcap.png` 是为本项目生成的专用凝胶材质光照纹理，以曲面法线采样，提供珊瑚粉透色、透明边层及细微折光。不是角色贴图、序列帧或替代身体的图片。
- `lib/studio-gel.ts` 控制内部亮纹、上下透色、底边与厚度。纹理中的两个固定光箱区域被柔化，主要高光改由世界空间 HDR 光箱环境和真实表面法线计算。
- 变形网格的前后深度支持 8 步有界光程搜索，折射体内气泡。空气球使用细分曲面、明暗环、小高光与深度吸收，按观察深度排序，光源反射位于气泡层上方。
- 眼睛使用单独的黑色物理材质，保留凸面反光；表面标记在主体后绘制，避免体内再出现一套假眼睛。接触影随压低的身体展开。
- WebGPU 全局使用 `NoToneMapping`，保留 sRGB 解码/编码，避免对已做显示变换的材质图再次压缩色调。`MeshBasicNodeMaterial.toneMapped=false` 本身不能关闭 WebGPU 的全帧色调映射。

这是为指定画风制作的实时材质，不是路径追踪。捕获图中的细小折光随观察法线采样；体内气泡折射仍采用代表深度，地面使用解析接触影，尚无任意场景的完整背景透射、多次散射或真实动态焦散。它适合当前浅色摄影棚，换环境需要重新校准。主要高光、身体、脸、气泡、旋转和形变均实时计算。

材质来源与提示词见 `assets/slime-gel-matcap.prompt.txt`。PNG 为 1254×1254 RGBA，SHA256：`ba67a97eda151db6ee9c84dadd3ac44d8ad2295b19fdedc082f08e8ef6388475`。透明外圈按白色合成，采样保持在球形材质的有效区域。

### 2026-09-09：连续曲线与饱满轮廓

按用户确认的方向，只重建形体，不用偏移冠部或调整镜头改变比较结果。自然姿态的宽度与厚度分别定义：上冠使用连续凸的解析曲线，下腹使用五次 Bézier，与冠部和接触底面均保持切线、曲率连续。这样上部收束、肩腹圆润，下腹柔和转入桌面，避免逐层插值带来的局部凹陷、肩部折带和长直侧壁。

顶点数仍为 8,962，改用余弦分布在顶部与底部加密采样。小脸重新贴合皮肤，主要气泡改用截面相对坐标；Puff 按两个方向独立缩放，保持鼓圆后的深宽比。材质、灯光、镜头和脸部尺寸沿用上一版。

新增六个归一化轮廓宽度带及连续凸性检查，同时检查实际导出网格的 Puff 截面、脸部附着、气泡包含和六种姿态取景。宽度带来自 AI 图的粗略边缘测量，容差为最大宽度的 2.5%；这是防止形体回退的检查，不代表完整轮廓与概念图逐像素一致。实际灰模、正面、侧面和形变截图保存在工作区 `outputs/softie-shape-qa`。本次仍只更新本地 `/lookdev`，完整玩法暂未替换该美术模型。

### 检查与性能

页面显示渲染回调频率。可用 `/lookdev?profile=1` 开启 GPU 诊断，读取画布容器的 `data-studio`：GPU 数值是一个采样帧所有 render pass 的执行时长之和，不含 CPU、浏览器合成或显示延迟；时间戳有量化误差。计时默认关闭；启用时清理 Three 0.183 保留的历史 UID，并在切换材质、姿态或尺寸后重置样本。当前设备的结果不能视为手机性能保证。
